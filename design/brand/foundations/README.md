# Параметры интерфейса Reflower

`tokens.css` — generated compatibility-экспорт общих размеров и поведения для
существующих веб-интерфейсов:

- шкала отступов `4–64px`;
- радиусы `4–16px`, карточка `12px`, таблетка `999px`;
- высоты элементов `40px` для компактной админки, `44px` по умолчанию и `48px`
  для сенсорных сценариев Mini App;
- границы, длительности переходов, слои и ширина боковой навигации.

В админке применяется утверждённая компактная плотность. Mini App и лендинги
подключают то же ядро и используют сенсорные или обычные роли, а не создают
собственные шкалы.

Файл вручную не редактируется. Канонические foundations находятся в
`design/design-system/tokens/primitives.json`, подробный контракт — в
`design/design-system/FOUNDATIONS.md`; экспорт обновляет
`python3 design/design-system/scripts/build_tokens.py`.
