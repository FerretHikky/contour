# Иконки

Единый продуктовый набор Reflower повторяет правила Stepin: сетка `24×24px`, контур
`2px`, круглые окончания и соединения. Пути основаны на Lucide Icons 1.25.0 (ISC).

Мастер-реестр — [`icons.js`](icons.js). Его копии в Mini App и админке должны быть
синхронны с мастером. Иконки загружаются локально, без CDN, наследуют цвет элемента
через `currentColor`, декоративные SVG скрыты от скринридера. Название действия всегда
остаётся текстом или `aria-label`: одна иконка не должна быть единственной подсказкой.

Эмодзи остаются только там, где это предметная иллюстрация или часть сообщения
Telegram. Брендовые зоны используют production‑логотип из `design/brand/logos/`, а
навигация, кнопки, меню и служебные статусы — SVG из общего реестра. Не добавляйте
другую библиотеку без унификации геометрии.

Общий snackbar использует четыре смысловых состояния из этого же реестра: `info` для
информации, `check` для успешного действия, `circle-alert` для ошибки и
`triangle-alert` для предупреждения. Цвет и иконка всегда меняются вместе, чтобы
состояние не передавалось одним только цветом.

Флаги для выбора языка лежат в [`flags/`](flags/) и не входят в контурный набор:
это цветные SVG из MIT-пакета `country-flag-icons` 1.5.19. В Mini App используются
точные копии мастеров для России, Великобритании, Кыргызстана и Узбекистана.
