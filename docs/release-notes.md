Contour 1.0.0 establishes the common source for Reflower and Lavlio. It includes existing tokens, light/dark themes, Core Web controls and behavior, iconography, the React Button/Icon/IconButton adapter, and the interactive component catalog. Existing rf-* CSS and token contracts remain compatible. Authentication, Telegram SDK, product data and product logos are excluded. Updates reach consumers as reviewed PRs; this release does not deploy products.
